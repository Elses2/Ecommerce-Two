    • showCheckout: function
      • showCheckout(req: Request, res: Response): void

        Renderiza el formulario de checkout con el resumen del carrito.

        Genera un checkoutToken nuevo por render (D6): el formulario lo devuelve oculto en el POST y, si el envío falla por validación, se re-renderiza con el MISMO token para que un reintento exitoso no cree órdenes duplicadas. Carrito vacío → redirect a /cart (no hay nada que pagar).

        Parameters

        • req: Request

          Objeto de solicitud de Express (requiere req.session).

        • res: Response

          Objeto de respuesta de Express.

        Returns void

        Renderiza la confirmación de una orden por su token de checkout (D7).

        El token identifica la orden (nunca se expone orders.id): formato inválido u orden inexistente → 404. La vista muestra los items con el unit_price congelado (spec §1.1) y los datos de envío de la orden.

    • submitCheckout: function
      • submitCheckout(req: Request, res: Response): void

        Procesa el formulario de checkout y crea la orden.

        El DTO se arma SOLO con los campos esperados del body (nunca con las líneas del carrito: esas salen de la sesión). Si la orden se crea (o es un reenvío idempotente del mismo token, D6) se vacía el carrito y se redirige a la confirmación; si falla la validación se re-renderiza el formulario con status 400, los errores, los valores tipeados y el MISMO token — el carrito de la sesión queda intacto.

        Parameters

        • req: Request

          Objeto de solicitud de Express (requiere req.body y req.session).

        • res: Response

          Objeto de respuesta de Express.

        Returns void
