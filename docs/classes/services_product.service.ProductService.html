    getRelated

    • getRelated(
          productId: number,
          categories: Category[],
          limit?: number,
      ): ProductView[]

      Productos relacionados (spec §6.8/Paso 8): comparten al menos una categoría con el producto dado, excluyéndolo; hasta limit resultados y, si hay más candidatos, se eligen al azar. La selección aleatoria vive acá (Fisher-Yates — el sort(() => Math.random() - 0.5) del pseudo-código del spec es un barajado sesgado); el SQL queda en el repository. Cada related sale como ProductView completo (fallback de imagen §2.3 + inStock §6.10).

      Parameters

      • productId: number

        ID del producto actual a excluir.

      • categories: Category[]

        Categorías asociadas al producto.

      • Optionallimit: number = 4

        Cantidad máxima de relacionados a retornar.

      Returns ProductView[]

      Arreglo de productos relacionados aleatorizados.
